# Speed Multi Breaker

Небольшой мод для **Minecraft 1.20.1 (Fabric)**, который добавляет гибкую настройку скорости добычи и копание по области для всех основных инструментов (кирок, лопат, топоров и мотыг).

## Основные возможности

* **Прогрессивная добыча по области:** блоки в выбранной сетке ломаются не мгновенно, а с учётом своей реальной прочности. Пока зажата кнопка копания, прогресс накапливается на каждом блоке отдельно — мягкие породы вылетают первыми, твёрдые доламываются следом.
* **Быстрые пресеты на лету:** переключение между готовыми режимами прямо в игре без ввода команд.
* **Визуальная 3D-рамка:** подсвечивает все блоки, которые попадут в зону копания, с учётом грани блока, на которую вы смотрите. Цвет рамки меняется в зависимости от выбранного режима.
* **Точечное копание на `Shift`:** если зажать приседание, область временно сбрасывается до `1×1`, чтобы можно было аккуратно убрать один блок и не задеть лишнего.
* **Гибкие тоннели:** можно задать любую асимметричную область копания (например, `1×2` или `2×3`) с помощью команды.
* **Сохранение настроек:** выбранный режим, скорость и размеры области сохраняются в данные мира и не сбрасываются после перезахода.

## Управление и режимы

Возьмите в руку любой инструмент (кирку, лопату, топор или мотыгу) и нажмите **`Shift` + `Ctrl` (клавиша бега) + `ПКМ`**, чтобы переключить режим:

1. **Обычный** — область `1×1`, скорость `1x`
2. **Быстрый** — область `1×1`, скорость `3x`
3. **Бур 3×3** — область `3×3`, скорость `6x`
4. **Уничтожитель** — область `5×5`, скорость `10x`

## Команды

Если стандартных пресетов не хватает, можно настроить параметры вручную:

* `/minspeedx <множитель>` — устанавливает множитель скорости добычи (от `0.1` до `100.0`).
  * *Пример:* `/minspeedx 2.5`
* `/minsizex <вверх><вправо><вниз><влево>` — задаёт расширение области от центрального блока в каждую сторону (4 цифры подряд).
  * *Пример:* `/minsizex 1000` — добавит 1 блок сверху (удобно для копания тоннелей `1×2`).
  * *Пример:* `/minsizex 1111` — область `3×3`.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net) для Minecraft **1.20.1**.
2. Скачайте и положите в папку `mods` библиотеку [Fabric API](https://modrinth.com).
3. Поместите `.jar` файл **Speed Multi Breaker** в папку `mods`.

## Лицензия

Проект распространяется под лицензией **CC0-1.0**. Вы можете свободно использовать мод в сборках или дорабатывать его код.
