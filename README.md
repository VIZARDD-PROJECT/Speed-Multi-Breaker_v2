# Speed Multi Breaker [SMB]

**Мод, который позволит копать много и быстро, а также имеет гибкую настройку (идеально подходит для людей с СДВГ).**

Надоело копать бесконечные туннели? С модом **Speed Multi Breaker** вы сможете прямо на лету настраивать область добычи и скорость копания, с лёгкостью прорубая любые шахты и проходы любыми инструментами (кирки, лопаты, топоры, мотыги).

## Преимущества и особенности

* **Настройка на лету:** легко меняйте скорость и размер добычи зажав комбинацию `Shift + Ctrl` (и `+ Alt` для размера области) и прокручивая колёсико мыши вверх или вниз.
* **Режим точности на `Shift`:** просто удерживайте приседание, чтобы временно сбросить область до `1×1` и ступенчато снизить скорость для аккуратной работы.
* **Гибкость под себя:** все кнопки-активаторы можно переназначить в настройках управления Minecraft (удобно даже при игре с телефона в PojavLauncher).
* **Ручной режим и копание в глубину:** для нестандартных задач есть команды `/minsizex 0000 0` (`<вверх><вправо><вниз><влево> [глубина]`) и `/minspeedx 1`. Например, `/minsizex 1111 10` прорубит тоннель `3×3` на `10` блоков вперёд одним ударом.
* **Подсветка и цветовая индикация:** 3D-рамка выделения и текст над хотбаром меняют цвет в зависимости от уровня скорости и размера сетки (включая подсказки для чётных размеров без центра).
* **Разумный имбаланс:** скорость подстраивается под самый твёрдый блок в сетке, а прочность инструмента честно тратится за каждый сломанный блок в сумме.
* **Удобный конфиг:** лимит скорости, шаг прокрутки, максимальный размер области и направление смещения для чётных сеток настраиваются через **Mod Menu** (с **Cloth Config API**) или в файле `config/speed-multi-breaker.json`.

## Установка

1. Установите **Fabric Loader** и **Fabric API** для Minecraft **1.20.1**.
2. Поместите файл мода в папку `mods`.
3. *(Опционально)* Установите **Mod Menu** и **Cloth Config API** для настройки параметров прямо в игре.
